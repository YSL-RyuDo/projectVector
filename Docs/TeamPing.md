# 팀 핑

클라이언트 YSL, 서버 main에 함께 적용한다. 기존 팀원의 Z 입력, 원형 선택, 카메라 연결을 유지하고 실제 팀 전송과 저장된 UI를 연결했다.

## 사용

- Z를 짧게 누르면 조준한 지형에 `여기` 표시.
- Z를 0.2초 이상 누르면 핑 휠. 위는 여기, 오른쪽은 위험, 아래는 공격, 왼쪽은 방어. 마우스로 고른 뒤 Z를 놓아 보낸다.
- 중앙에서 Z를 놓으면 취소한다. 허공을 가리키면 전송하지 않고 안내한다.
- TestMap의 바닥·벽은 `MiniMap` 레이어도 사용하므로 조준 판정에 포함한다. 미니맵이라는 이름만 보고 레이어 전체를 제외하면 실제 지형에도 핑을 찍을 수 없다.
- 서버가 승인한 핑만 자신과 같은 팀에게 표시한다. 월드 화면에는 종류, 발신자, 거리, HUD와 확대 미니맵에는 같은 위치의 아이콘이 표시된다.
- 핑은 위치에 고정되고 3초 뒤 사라진다. 상대를 자동 탐지하거나 움직임을 추적하지 않는다. 같은 팀원의 새 핑은 그 팀원의 기존 핑을 교체한다.
- 휠을 고르는 동안 카메라 조준 입력과 발사, 재장전 시작, 무기 교체, 스킬 입력을 막는다. 일반 이동과 네트워크 처리는 유지한다. 설치·해체 중에는 핑 휠을 열지 않는다.
- 채팅, 설정, 음성 설정, 자유 커서를 사용하는 화면에서는 핑 입력을 받지 않는다. 사망·관전 중에는 보내지 못하지만 같은 팀의 표시를 받을 수 있다. 사설방 중립 관전자에게는 팀 핑을 보내지 않는다.
- 라운드 종료·초기화, 팀 변경, 연결 해제 때 이전 표시를 정리한다. 재접속 시 지난 핑은 다시 재생하지 않는다.

## UI

`Assets/ProjectVector/Modules/Match/UI/Ping/TeamPingHUD.prefab`에 휠, 종류별 벡터 아이콘, 한국어 글꼴, 표시 슬롯 6개, 거리·이름, 미니맵 표시, 안내 문구, 수신음을 저장했다. `Game_TestVersion` 씬에는 해당 프리팹 하나만 연결한다. 기존 화면과 버튼은 유지한다. 런타임에서는 저장된 슬롯의 데이터, 위치, 색상, 표시 여부만 갱신하며 Canvas나 텍스트, 휠을 새로 만들지 않는다.

기본 팔레트는 청색 위치, 적색 위험, 황색 공격, 청록색 방어다. 색상 외에도 위치 표식, 경고 삼각형, 이중 화살표, 방패 모양으로 종류를 구분한다. 조준점 근처에서는 표시 투명도를 낮추고 마지막 0.35초에 사라진다.

`Project Vector/UI/Author Team Ping HUD`는 에디터 작성 도구다. 플레이 중이나 저장하지 않은 씬에서는 실행하지 않는다. 재작성하면 기존 핑 전용 오브젝트와 프리팹만 갱신한다.

## 서버

- 415 요청: 16바이트 요청 ID, 종류, XYZ. 클라이언트는 발신자·팀을 지정하지 못한다.
- 416 확정: 서버 이벤트 ID, 발신자, 팀, 종류, 수명, XYZ. 기존 패킷 레이아웃은 변경하지 않았다.
- 인증, 게임 상태, 방 소속, 생존, 복원 상태, 종류, 유한 좌표, 좌표 안전 범위, 거리, 중복 요청과 빈도를 검사한다.
- 거리 한계는 서버 플레이어 위치 또는 서버가 보유한 본인 드론 위치에서 155m이며 클라이언트 조준 레이는 150m다. 좌표 안전 범위는 X/Z ±200m, Y -30~100m다. 이는 세 맵을 포함하는 비정상 좌표 차단용 범위이며 정확한 맵 충돌·시야 검사가 아니다.
- 최대 3회 분량의 요청 여유, 초당 1회 분량 회복, 최소 간격 0.35초. 클라이언트는 0.45초 간격과 같은 여유 제한을 적용한다.
- 같은 방, 같은 팀에게만 확정 패킷을 전달하며 상대 팀과 중립 관전자는 제외한다. 복원 중인 연결에는 보내지 않으며 재접속 기록에도 저장하지 않는다.

## 검증 도구

- `Tests/TeamPingTests.cpp`: 실제 서버 처리와 소켓으로 같은 팀 3명 전송, 적·관전자 배제, 중복·빈도·좌표·사망·잘못된 방 거부, 드론 기준 거리, 재접속 기록 제외를 검사.
- `PingVerification.Run`: 씬 참조, 저장된 UI·글꼴·음원, 선택 방향과 취소, 팀 필터, 중복 제거, 발신자별 교체, 세션 초기화, 패킷 파싱, 실행 중 UI 계층 수 보존을 검사.
- `Tests/SixClientLifecycle.py <빌드 폴더> TestMap --ping`: 별도 계정 데이터와 실제 Unity 클라이언트 6개로 Z 입력, 네 종류, 양 팀 격리, 설정창, 수명, 재접속 후 재수신을 검사. 테스트 전용 개발 빌드와 명시적 환경 변수에서만 동작한다.
