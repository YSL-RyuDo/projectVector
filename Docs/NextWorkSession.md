## 3. 우선 작업: 음성채팅 최소 기능

### 인증과 연결

- [ ] 기존 게임 계정 로그인과 음성 인증의 연결 방식을 먼저 결정한다.
  - 현재 패키지에는 Unity Authentication을 별도로 추가하지 않았다.
  - Unity Authentication을 사용할지, 기존 게임 서버가 Vivox 토큰을 발급할지 결정한 뒤 필요한 의존성만 추가한다.
  - 임시 익명 인증을 사용하더라도 실제 게임 계정과 동일한 것으로 취급하지 않는다.
  - 운영용 서명키는 서버에만 둔다. 클라이언트 Test Mode로 배포하지 않는다.
- [ ] 음성 초기화 → 인증 → Vivox 로그인 → 채널 입장 → 퇴장/로그아웃 순서를 구현한다.
- [ ] 음성 연결 실패·권한 거부·타임아웃이 기존 게임 로그인이나 매칭을 막지 않게 한다.
- [ ] 중복 초기화, 씬 이동, 재로그인, 네트워크 재접속 시 채널/이벤트 핸들러가 중복으로 남지 않게 한다.

### 음성 채널 범위

- [ ] 로비 파티 채널과 경기 팀 채널의 입장·전환·종료 시점을 정의한다.
- [ ] 상대 팀에게 팀 음성이 들리지 않게 서버의 실제 파티/팀 소속으로 권한을 확인한다. 채널 이름을 숨기는 것만으로 보호하지 않는다.
- [ ] 파티 탈퇴·강퇴·매치 종료·로비 복귀·연결 종료 시 이전 채널에서 빠지는지 확인한다.
- [ ] 사설방·관전·사망 상태에서 누구와 통화할 수 있는지 규칙을 정하고 적용한다. 아직 결정하지 않은 범위를 임의로 전체 공개하지 않는다.

### 입력과 설정

- [ ] 기본 모드: `~`가 적힌 키를 누르는 동안만 송신한다. 한국어 키보드의 백틱/물결 키와 Shift 조합을 실제로 확인한다.
- [ ] 자동 음성 감지 모드를 별도 선택지로 제공한다. 기본값은 눌러서 말하기로 둔다.
- [ ] 채팅 입력·팝업·창 포커스 상실 중 의도치 않은 송신과 키 충돌을 막는다. 키를 뗐거나 포커스를 잃으면 송신을 멈춘다.
- [ ] 마이크/출력 장치, 입력·출력 음량, 자기 음소거, 개별 상대 음소거를 구현한다.
- [ ] 자동 음성 감지의 임계값을 테스트하고 숨소리·키보드 소음에 계속 송신되지 않게 조정한다.
- [ ] 마이크 권한 거부, 장치 미연결·분리 상황을 처리한다.
- [ ] 발화 표시와 설정 UI가 필요하면 기존 화면 구조를 보존하면서 Scene/Prefab Hierarchy에 저장한다. 런타임에서 새 UI 구조를 생성하거나 재배치하지 않는다.
