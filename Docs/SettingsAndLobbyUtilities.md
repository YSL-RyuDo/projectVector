# 공통 설정과 로비 유틸리티

`Assets/ProjectVector/Shared/UI/Settings/VectorSettings.prefab`이 공통 설정 화면이다. Login, Lobby, Game_TestVersion, WeaponTest, RankResult, Result 씬에 편집 가능한 프리팹 인스턴스가 저장되어 있다. 첫 인스턴스가 씬 전환 후 유지되고 이후 인스턴스는 제거된다. UI는 Play 전에 작성되며 런타임에는 화면을 생성하지 않는다.

## 사용 흐름

- 로비 우측 메뉴 → 시스템 설정 / 공지 / 교환 코드 / 고객센터 / 게임 종료.
- 모든 활성 빌드 씬에서 ESC → 공통 설정. 입력 중인 채팅이나 열린 음성 패널은 먼저 닫힌다.
- 일반, 조작, 감도, 조준선, 화면, 오디오의 6개 탭. 컨트롤러 탭은 없다.
- 행에 마우스를 올리거나 선택하면 우측 설명이 바뀐다.
- 감도·조준선·키 지정·소리·그래픽 품질은 즉시 반영되고 로그인 중에는 변경이 멈춘 뒤 약 0.8초 후 계정에 자동 저장한다. 적용 또는 닫기를 누르면 대기 중인 저장을 바로 요청한다. 현재 탭 기본값은 해당 탭만 초기화한다. 디스플레이 모드와 해상도는 적용 후 15초 확인을 거친다.
- 조준선 `PV1-` 코드는 버전, 모든 모양 값, 체크섬을 포함한다. 잘못된 코드는 현재 값을 바꾸지 않는다.
- 연습장 훈련 설정은 F3 또는 훈련 콘솔의 상호작용으로 연다. ESC는 공통 설정에 사용한다.

## 연동과 저장

로그인 성공 후 `NetworkManager.AccountSettings`가 서버 패킷 432/433으로 해당 계정의 설정을 먼저 불러온다. 서버가 확인되기 전에는 설정 편집을 잠그고, 수신한 값을 로비와 인게임에 공통 적용한다. 일반·감도·조준선·화면 품질·오디오 설정, 20개 조작 키, 확인한 화면 모드와 해상도, 선호 음성 장치를 동기화한다. 다른 PC도 같은 서버에 로그인하면 같은 설정을 불러온다.

기존 `MouseSensitivity_General/Horizontal/Vertical`, `Vector.Setting.*`, `Vector.Key.*`, `VectorVoice.*` PlayerPrefs는 게임 코드가 읽는 적용 값으로 유지한다. 계정별 마지막 서버 버전·동기화 값·미전송 값은 `Vector.Settings.Account.<계정 ID base64>`에 별도 캐시한다. 캐시가 없는 계정에 이전 계정의 값을 복사하지 않는다. 서버 설정이 없는 첫 계정에만 기존 PC 설정을 한 번 가져오고, 이후 새로운 계정은 기본값으로 시작한다.

서버 저장 성공 응답을 받은 뒤에만 저장 완료를 표시한다. 통신 오류와 저장 실패는 미전송 값을 보존하고 재시도한다. 재접속 때는 서버를 먼저 조회한 뒤 기준 버전이 같으면 미전송 값을 저장한다. 다른 PC에서 이미 더 최신 버전을 저장했다면 서버 값을 적용하여 덮어쓰기를 막는다. 충돌한 이 PC의 미전송 값은 캐시 키 뒤 `.ConflictBackup`에 남긴다. 종료 직전에는 저장 요청과 로컬 캐시 기록을 수행하며, 응답을 받지 못하고 종료되면 다음 로그인에서 재시도한다.

해상도는 모니터별 목록 번호가 아닌 가로·세로 크기로 저장한다. 현재 PC에서 지원하지 않는 해상도는 현재 화면으로 대체하고, 없는 음성 장치는 사용 가능한 기본 장치로 대체한다. 이 경우 계정에 저장한 선호 값은 변경하지 않는다. 해상도 확인을 취소하거나 시간이 만료되면 임시 선택은 서버에 올리지 않는다.

Unity 클라이언트와 서버를 함께 업데이트해야 한다. 기존 서버에는 설정 동기화 패킷이 없으므로 새 클라이언트만 배포하면 서버 확인을 완료할 수 없다. 이 기능은 설정 6개 탭의 계정 동기화이며, 다른 플레이어별 개별 음성 음소거/볼륨과 연습장 훈련 상태는 기존 저장 방식을 따른다.

이동, 점프, 앉기, 발사/정조준, 재장전, 무기 슬롯, 버리기, 상호작용, C/Q/E/X 스킬 및 음성 키가 실제 입력 코드에 연결된다. 드론 조작도 이동 키와 감도를 공유한다. ESC/Enter/Tab/B/Z/F3/F10 등 메뉴·소통 단축키는 고정이다. 설정을 닫은 직후의 UI 입력이 전투에 전달되지 않도록 프레임 차단을 유지한다.

`SettingsMenu`의 공개 진입점과 기존 직렬화 필드는 호환용으로 남아 있다. `GameplayActionPolicy`, 음성, 채팅, 점수판도 공통 화면의 입력 점유를 확인한다. 서버 수신, 라운드 시간과 원격 플레이어 처리는 중지하지 않는다.

음성 장치와 볼륨은 기존 `VectorVoiceChat` 서비스를 사용한다. 별도 음악 채널이나 외부 그래픽 플러그인처럼 현재 프로젝트에 없는 기능은 표시하지 않는다. URP 품질 설정은 런타임 복제본에 적용하여 원본 렌더 파이프라인 에셋을 변경하지 않는다.

공지/교환/문의는 서버 패킷 430/431을 사용한다. 서버 없는 상태에서 가짜 성공을 표시하지 않는다. 재화는 서버가 반환한 `MoneyManager` 잔액으로만 갱신한다. 서버의 `Docs/LobbyUtilities.md`에 운영 파일 형식이 설명되어 있다.

## 편집과 검증

메뉴 `Project Vector > Authoring > Install shared settings and lobby utilities` 또는 배치 `VectorSettingsAuthoring.Install`로 저장된 프리팹을 다시 작성한다. 씬을 저장하고 다른 Unity 프로세스가 프로젝트를 열고 있지 않을 때만 실행한다. 로비 버튼은 `VectorLobbyMenuButton`을 통해 유지 중인 인스턴스를 찾아 연다.

- `VectorSettingsVerification.AuthorAndRender`: 작성된 6개 씬의 참조를 검사하고 6개 탭 및 팝업 PNG를 OS 임시 디렉터리 `VectorSettingsVerification`에 출력한다.
- `VectorSettingsVerification.Run`: Play 모드에서 ESC, 키 변경/차단, 감도 호환, 조준선 코드 검증, 연습장과 로비 전환 및 메뉴 재진입을 검사한다. 기존 설정값을 임시 파일에 백업하고 종료 시 복원한다.
- `VectorAccountSettingsVerification.Run`: 형식 검증, 기존 설정 이관, 새 PC 자동 적용, 계정 분리, 자동 저장, 저장 중 추가 변경, 오프라인 재시도, 버전 충돌 및 실패 처리를 검사한다. 기존 PlayerPrefs를 복원하고 서버 통합 검사에 쓸 프로필을 OS 임시 디렉터리 `VectorAccountSettingsVerification/profile.txt`로 내보낸다.
- 서버 `Tests/AccountSettingsIntegration.py`: 내보낸 Unity 프로필로 실제 TCP 저장·로그인 재조회·서버 재시작·계정 분리·잘못된 값·쓰기 실패를 검사한다.
- 서버 `Tests/AccountSettingsUnityIntegration.py`: 임시 서버와 테스트 계정을 만들고 `VectorSettingsVerification.RunNetworkAccount`를 실행한다. 실제 Unity `SendLogin` → 프로필 수신 → UI 적용 버튼 → 서버 저장 응답 → 새 접속 조회를 확인한 뒤 기존 Play 회귀 검사도 실행한다. 이미 열린 Unity나 사용 중인 9000 포트가 있으면 실행하지 않는다.
- 서버 `Tests/LobbyUtilityIntegration.py`: 새 임시 데이터와 별도 서버 프로세스만 사용하여 코드 지급, 중복, 만료, 실패 복원, 문의 저장/재시도/제한/재시작을 검사한다.
